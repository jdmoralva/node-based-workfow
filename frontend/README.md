# Frontend

The root `.html` files are generated by the `DashboardShell` module source in `frontend/src/dashboard_shell/`.

## Run

Open `frontend/index.html` directly in a browser. The sidebar links navigate to the other static HTML pages.

To rebuild generated pages after editing shell sources:

```bash
python frontend/scripts/build_dashboard_shell.py
```

## Notes

- Fonts are local under `frontend/assets/fonts/`.
- The reusable icon source sprite lives in `frontend/assets/icons/sprite.svg`.
- All generated pages now share one global stylesheet: `frontend/style.css`.
- Each generated page keeps an inline runtime sprite so icons work correctly when opened via `file://`.
- Card selection behavior lives in `frontend/assets/js/controllers/card-selection-controller.js` and is loaded by `frontend/assets/js/pages/card-grid-page.js`.
- Tree toggle behavior lives in `frontend/assets/js/controllers/tree-toggle-controller.js` and is loaded by `frontend/assets/js/pages/creditcard-service-page.js`.
- Generated pages use an inline module bootstrap adapter because external module scripts are blocked on `file://` in Chrome.
